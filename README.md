One line under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation.

`main.ts` (Node 22, stdlib only) writes the reply to `/output/entry.txt`. The output is deterministic — two runs write identical bytes.

## Run

```sh
node main.ts
cat /output/entry.txt
```
